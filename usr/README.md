# سكنات اقاريو العربية (Agario Arabia Skins)

تطبيق مخصص للاعبي "اقاريو العربية" (Agario Arabia) يتيح لهم استعراض السكنات الشهيرة، نسخ أكوادها، وتصميم سكنات جديدة ومشاركتها.

## المميزات
- **الرئيسية**: استعراض قائمة متجددة من أحدث السكنات مع إمكانية نسخ الكود الخاص بكل سكن بنقرة واحدة.
- **تصميم سكن**: واجهة مبسطة لإنشاء سكن جديد عبر إدخال اسمه ورابط الصورة.
- **حسابي**: صفحة شخصية تعرض معلومات اللاعب والسكنات المفضلة والإعدادات.
- **دعم اللغة العربية**: واجهة مستخدم كاملة باللغة العربية (RTL).
- **تصميم عصري**: ألوان داكنة تتناسب مع أجواء الألعاب.

## التقنيات المستخدمة
- إطار العمل: Flutter
- لغة البرمجة: Dart

## كيفية التشغيل
1. تأكد من تثبيت بيئة Flutter.
2. قم بتشغيل الأمر `flutter pub get` لتنزيل الحزم المطلوبة.
3. قم بتشغيل التطبيق باستخدام الأمر `flutter run`.
